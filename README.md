# Vituss Britva

Приложение для Android и Windows с каталогом рабочих ссылок на популярные онлайн-казино. Ссылки обновляются автоматически — рабочий вход всегда под рукой, искать новое зеркало вручную не нужно.

## Зачем это нужно

Официальные домены казино регулярно блокируют, сохранённая ссылка перестаёт открываться без предупреждения, а в поисковой выдаче всё чаще мусор — дорвеи и старые статьи вместо рабочего адреса. Vituss Britva решает эту проблему: каталог сам подставляет новое рабочее зеркало вместо заблокированного домена.

## Что в каталоге

- **Популярные** — казино с самой активной аудиторией прямо сейчас.
- **Новые** — свежие площадки.
- **Легендарные** — бренды с многолетней историей на рынке.

## Как начать

1. Скачайте APK для Android или установщик для Windows по ссылкам ниже.
2. Разрешите установку из неизвестных источников — стандартное системное предупреждение.
3. Откройте приложение, выберите категорию и переходите по рабочей ссылке.

Регистрация в самом приложении не нужна.
