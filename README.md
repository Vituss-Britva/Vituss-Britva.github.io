# Vituss-Britva-Apps
Приложение Vituss Britva — каталог 30+ топовых игровых проектов Vituss Britva — приложение для Android и ПК с рабочими зеркалами популярных онлайн-казино. Актуальные ссылки обновляются автоматически внутри приложения — без поиска в Яндексе, заблокированных сайтов и дорвейных страниц.
